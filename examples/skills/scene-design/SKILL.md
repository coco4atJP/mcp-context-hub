# Scene design

Identify the subject, intended viewpoint and desired mood from the request. Use those decisions to choose composition, lighting and materials together.

Establish the camera and the subject's silhouette before detailing geometry. Keep the subject distinguishable from the background through value, color or depth. Add secondary objects only when they support the requested scene.

Use a preview from the connected application to judge framing, readability, surface appearance and distracting elements. Change the property responsible for the visible mismatch and preview again. Evaluate the result at the intended output size before increasing render quality.

Use the attached application workflow skill for tool operations; obtain current tool names and argument schemas from the Hub.
